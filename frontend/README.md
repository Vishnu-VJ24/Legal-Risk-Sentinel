# Frontend Workspace

This is the React + Vite frontend for Legal Sentinel.

## Scripts

```bash
npm ci
npm run dev
npm run build
npm run lint
```

## API configuration

- Default API base: `/api`
- Optional override: `VITE_API_BASE_URL`

During local development, Vite proxies `/api` to `http://127.0.0.1:8000`.
